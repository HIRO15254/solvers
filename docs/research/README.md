# Research documents

This directory contains non-normative surveys, design exploration, and inputs
to future decisions.

- [`solver-survey.jp.md`](solver-survey.jp.md) — solver design survey.
- [`blueprint-design.md`](blueprint-design.md) — blueprint research design.
- [`active/`](active/) — current plans, proposed designs, and unresolved
  decision inputs.

Once a proposal is accepted, update the applicable normative specification,
implementation guide, runtime, tests, and examples together. Measurements that
support current behavior belong in [`docs/validation/`](../validation/README.md).
