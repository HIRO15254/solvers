# Validation evidence

This directory contains reproducible fixtures, machine-readable measurements,
and reports that support the current implementation. It is evidence, not a
normative specification. The source-of-truth order is defined by
[`docs/README.md`](../README.md).

## Current indexes

- [`multiway-benchmarks-2026-09-09.md`](multiway-benchmarks-2026-09-09.md) —
  retained Multiway benchmark catalog and priorities.
- [`multiway-benchmark-config-index-2026-09-09.md`](multiway-benchmark-config-index-2026-09-09.md) —
  content-addressed configuration inventory.
- [`multiway-benchmark-runs-2026-09-09.md`](multiway-benchmark-runs-2026-09-09.md) —
  execution ledger.
- [`gto-wizard-validation.md`](gto-wizard-validation.md) — postflop external
  comparison procedure and retained records.

Plans, proposed designs, and unresolved next steps belong under
[`docs/research/`](../research/) so that an agent cannot mistake them for
validated behavior. Date-stamped evidence stays here until a later archival
pass can move it without breaking references.
