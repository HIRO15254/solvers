The uploaded cloud source and first local smoke predate one allocation-only optimization in l1/solve.rs: with a current-strategy Mapping (QRE mode), reuse the already-computed `rows` instead of calling `storage.profile(subtree, false)` a second time. Current rows and returned values have identical bits; no reach, mapping, regret, average or state semantics change. Full cloud timing therefore includes this redundant profile construction. Final source uses the shared rows; final local smoke is recorded separately.
