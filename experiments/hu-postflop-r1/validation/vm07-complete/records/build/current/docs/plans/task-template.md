# 作業票テンプレート

仕様・手順・受入条件はこの様式で必要な分だけ記録する。
担当・状態・優先度・ブロッカー・次の一手はLinearに置く。[ID対応](../status.jp.md)にIssueを登録し、状態をここへ転記しない。

- 作業ID / 関連要件ID / Linear Issue:
- 目的・利用者に届く結果:
- 対象 / 対象外:
- 依存する成果物・先行作業:
- 規範・設計・既存証拠:
- 編集する範囲・並行作業との境界:
- 成果物・保存先:
- 完了条件:
- 必要な検証・追加受入:
- 証拠の参照: source、実行条件、結果、残る制限。現在の作業状態は含めない。

未作成の成果物は予定として記し、存在する証拠へのリンクと区別する。
既存実装があること、testが通ること、製品品質が受け入れられることを別々に確認する。
