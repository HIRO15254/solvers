# VM20 使用量と未使用予約額の再評価

削除済み VM20 の取得済み使用量と実際のライフサイクルから、予約 $1.85 のうち **$0.50 の復活、$1.35 の保持**を提案する。台帳の変更、請求額の確定、性能改善の採用を意味しない。監査時の台帳 $39.15 保持 / $0.85 利用可能に適用した場合は $38.65 保持 / $1.35 利用可能となる。

`report02.json` が最終提案。初回の $1.40 提案は `report.json` と `analyze.py` にそのまま保存し、`analyze02.py` が全入力を再検証して初回結果とバイト一致を確認してから、予約額の丸めのみを変更する。

## 取得と対象

- Project `solvers-abstraction-20260723`、instance ID `2562385330130146252`、`us-central1-b`。
- 2026-09-28 04:29:20.103183 UTC の起動から、05:01:08.496 UTC の削除完了、05:02:08.001102 UTC の全リソース不在確認まで。
- 同一 ID の `e2-standard-2` → `e2-highcpu-32` → `e2-standard-2`、8 件の DONE 操作、固定 STOP 期限、20 GiB の同一ディスク、および VM・disk・address の空一覧を確認。
- 公式 Monitoring API への GET は 2 回、双方 HTTP 200、各 31 点。取得した sent bytes は **179,843,801 bytes**、uptime は **1,629.719074 秒**。SCP の検証済みアーカイブ転送は 172,135,766 bytes。アーカイブ展開なし。
- 既存 SDK の認証をメモリ内で利用。資格情報は保存していない。小さい既存証拠とレスポンスのみを保持。

## 費用モデル

停止時間を差し引かず、全期間を通常料金の 2 vCPU とし、その上に 32 vCPU の可能期間を重ねる。それぞれに 120 秒を加算し、分単位で切り上げる。ディスクも作成から不在確認までに 120 秒を加算する。

| 内訳 | 条件 | USD |
|---|---|---:|
| 2 vCPU | 全期間 35 分 × 通常 $0.06701142/h | 0.039089995 |
| 32 vCPU | stop 開始から縮小完了までを重ねて 10 分 × 通常 $0.79152384/h | 0.131920640 |
| 外部 IPv4 | 全期間 35 分 × $0.0025/h | 0.001458333 |
| disk | 20 GiB × 35 分 × $0.000137/GiB/h | 0.001598333 |
| 外向き転送 | 元の 0.5 GiB 下限 × $0.30/GiB | 0.150000000 |
| 元の不確実性予備費 | 維持 | 1.000000000 |
| 合計 | | **1.324067301667** |

VM19 の analyzer は $0.10 単位の切り上げを明示している。1.264 → 1.30 という結果だけでは $0.05 方針の根拠にならない。一方、全監査で固定された最小丸め幅は見つからず、VM16 などは明示的な細粒度への変更を別案として記録している。初回 $1.40 はこの $0.10 切り上げを継承した値であり、追加費目ではない。

今回、取得後の root の依頼と合意により、**$0.05 単位の上方丸め**を明示的に採用した。合計と各費目、元の $1 予備費、512 MiB の転送下限、各 120 秒、重複した計算時間は変更していない。保持額 $1.35 はモデル合計を $0.025932698333 上回る。残予算に合わせてモデル費用を下げたものではない。

## 限界と再検証

Monitoring は請求書でも完全な Billing export でもない。最初の DELTA は起動前の一部を含み、最後は 05:01:00 UTC までである。60.001 秒の内部欠落と境界・細かい時間差を記録し、未知の使用量をゼロ扱いしていない。削除直後の取得には報告遅延もあり得る。観測 uptime を課金時間から差し引かず、観測転送すべてを外向き転送の枠に含める。

監査スクリプトは外部通信、SDK 実行、台帳更新、VM 操作を行わない。ローカル実行は小さい JSON の再検証のみ。

```text

C:/Python313/python.exe -X utf8 -B experiments/hu-postflop-r1/cloud/usage-audit-vm20/analyze02.py --check
C:/Python313/python.exe -X utf8 -B experiments/hu-postflop-r1/cloud/usage-audit-vm20/test_analysis.py
```

`checks.json` に実行結果とソース・結果のハッシュを保持する。
