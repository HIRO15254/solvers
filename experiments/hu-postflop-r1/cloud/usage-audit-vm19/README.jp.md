## 寿命と費用

当初の45分STOPは2026-09-27 09:19:48 UTC。実際はSpot preemptionが09:15:09 UTCに記録され、
`lastStopTimestamp` は09:15:25.078 UTC。翌日の回収は元実験とは分け、明示された
600秒の回収専用amendmentに従う。回収の要求は2026-09-28 04:05:18.452864 UTC、
削除完了は04:11:52.051 UTC。回収用STOPは04:14:34 UTCであり、実験を継続したことにはしない。

計算は元の稼働窓と回収窓にそれぞれ120秒を加え、各分に切り上げる。
43分 + 9分 = 52分をCPU・IPv4に計上する。20 GiB diskは停止中も課金対象として、
作成から翌日のdisk不在確認までの全期間に120秒を加え、1180分を計上する。
