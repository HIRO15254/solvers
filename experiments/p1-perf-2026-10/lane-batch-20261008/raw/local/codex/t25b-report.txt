Kernel layout and grouping:
T25a API eval_cfr_batch accepts arbitrary terminal IDs (including repeats), opponent slices and separate zeroed output rows.
Evaluator maps river folds to existing showdown rank tables at construction, sorts reused TLS indices by table, then dispatches widths1..8.
Early folds/runouts without a single table and f64 precision fall back to eval_cfr. Default trait API calls eval_cfr once per terminal.
Kernel TLS float vectors use active prefixes (opp_support+1)*L and own_support*L; only sentinel row cleared, live values written, caller outputs cleared.
Active reach+value prefixes: BTN/BB27,168B and wide69,216B atL8. Stack card sums52*L floats plus lane vectors.
Tied hands are reread instead of resetting52*L group sums; interleaved output is copied to separate terminal rows.
Linked width8 kernel frame2,904B; evaluator entry552B. Engine frames1,080..1,128B, rather than the original87KiB fixed stack prototype.
Warm calls allocate no new buffers; first use/growth can allocate and worker high-water capacities are retained.

Engine:
Entry: F32 && Action && !subtree_has_chance[node] && subtree_elements(node)<2*ACTION_PAR_MIN_ELEMENTS (32768).
Exactly the ActionViews Ambient bound, entered at the first eligible recursion node; no internal recursive traversal or parallel actions.
Verified fill reserves contiguous sibling blocks; parent IDs precede children and descendants are a contiguous interval excluding the root.
A metadata-only sizing walk finds the descendant end/max own work length, then three phases:
1. Root then ascending descendants: regret matching; actor-scaled child reaches; unchanged reaches share root/ancestor offsets.
2. One eval_cfr_batch over the collected terminal IDs and separate zeroed value rows.
3. Descending descendants then root: own CFV/action-order sums; v_a-CFV; update_regrets then accumulate_strategy with phase1 own-reach*sigma rows.
Opponent CFVs sum children in child order. PRUNE skips matching at zero-opp opponent nodes and excludes zero-reach terminals; own descendants still update.
All-zero rows stay shared. PRUNE false evaluates zero reaches. Root output receives its value row.
Four LIFO scratch float arenas: sigma and scaled reaches mirror storage span, node values use nodes*own_support, work uses largest own action block.
Leased TLS metadata uses node reach offsets, terminal IDs and empty recycled reference vectors. No RefCell borrow crosses evaluator calls.
Safe in-place collect recycles empty reference-vector allocations across lifetimes; debug checks verified pointer retention on the installed standard library.
Old T20/T21 hooks remain outside eligible subtrees; f64 recursive match, EV/BR/evaluation passes and file formats unchanged.
Other evaluators use the batch default; engine/toy tests show exact values/state for the independent evaluator.
